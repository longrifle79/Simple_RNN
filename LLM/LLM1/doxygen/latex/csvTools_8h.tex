\doxysubsection{Detailed Description}
Header file for CSV parsing and printing utilities in the Simple\+NN project. 

Declares functions for:\+
\begin{DoxyItemize}
\item Parsing individual CSV files into 2D nested lists of floats.
\item Printing single or multiple parsed CSV tables.
\item Loading all CSVs from a directory into a 3D structure.
\end{DoxyItemize}

These utilities form the data ingestion layer for regression datasets, supporting header skipping, basic numeric parsing, and structured output.

\begin{DoxyNote}{Note}
Designed for simple numeric CSVs (no quoted fields, no escaped commas). Assumes consistent row lengths and float-\/convertible values. For advanced CSV handling (quotes, strings, large files), consider third-\/party libraries.
\end{DoxyNote}
