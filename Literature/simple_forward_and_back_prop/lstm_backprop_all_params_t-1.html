LSTM Backpropagation — Updating Every Weight and Bias

All twelve parameters at time step t−1, using the same path-diagram approach: every gradient is a path, and every path segment is one derivative.

About this document. The previous document followed a single weight, \(w_{xo_{t\text{-}1}}\), along its path to the loss. This one updates all twelve parameters — and the key to keeping it simple is that we do not compute twelve separate long chains. The paths share segments. All twelve start with the same first step. Six of them share the entire journey down to the cell state. Within each gate, the three parameters differ only in the very last factor. So the real work is: a few shared trunk computations, then short branch-specific endings.

How to read it: the map below shows every path at once. Then we compute the shared trunk, then walk each branch. Every number gets derived exactly once and reused.

Forward-pass values (all fixed, known data from the t−1 pass)

  • Inputs: \(x_{t\text{-}1}=0.5\),   \(h_{t\text{-}2}=0\),   \(c_{t\text{-}2}=0\)
  • Forget gate: \(\text{net}_f=0.35\), \(f_{t\text{-}1}=0.5866\)
  • “% Potential Memory” (sigmoid): \(\text{net}_{i1}=-0.05\), \(i1_{t\text{-}1}=0.4875\)
  • “Potential Long Memory” (tanh): \(\text{net}_{i2}=0.65\), \(i2_{t\text{-}1}=0.5717\)
  • Cell state: \(c_{t\text{-}1} = f\cdot c_{t\text{-}2} + i1\cdot i2 = 0.2787\),   \(\tanh(c_{t\text{-}1})=0.2717\)
  • Output gate: \(\text{net}_o=0.1\), \(o_{t\text{-}1}=0.5250\),   output \(h_{t\text{-}1}=0.1426\)
  • Target \(=0.8\), loss \(L=(0.8-0.1426)^2=0.4321\), learning rate \(\alpha=0.1\)

The Map — All Twelve Paths at Once

Read this backward from the loss (right to left), the direction the gradient actually travels. Every parameter’s path begins with the same segment (L back to h). Then it splits: the output gate’s three parameters branch upward; everything else rides down through \(\tanh(c)\) into the cell state, where the path splits three ways — one branch per block that built \(c_{t\text{-}1}\).

The full gradient map. Twelve parameters, but only a handful of distinct segments — the trunk is shared, and each branch point contributes exactly one chain-rule factor. The forget branch is grayed out: its very first factor is \(c_{t\text{-}2}=0\), which zeroes everything downstream of it.

The Shared First Step — \(\partial L / \partial h_{t\text{-}1}\) (used by all twelve parameters)

Every parameter influences the loss only through the output \(h_{t\text{-}1}\), so every path starts with the same derivative — computed once, reused twelve times:

Symbolic, then numbers
\[ \frac{\partial L}{\partial h_{t\text{-}1}} = -2\,(\text{target} - h_{t\text{-}1}) = -2\,(0.8-0.1426) = \mathbf{-1.3147} \]
Negative: the output was too low, so anything that raises \(h\) lowers the loss. Keep \(-1.3147\) in hand — it is the first factor of every chain below.
Branch 1 — The Output Gate: \(w_{xo_{t\text{-}1}}\), \(w_{ho_{t\text{-}1}}\), \(b_{o_{t\text{-}1}}\)

The output-gate path. Identical to the single-weight document — except now we use the leftmost segment three times, once per parameter.

The two path segments (shared by all three parameters)

Step O1 — through the multiplication h = o × tanh(c)
\[ \frac{\partial h_{t\text{-}1}}{\partial o_{t\text{-}1}} = \tanh(c_{t\text{-}1}) = \mathbf{0.2717} \]
Step O2 — through the sigmoid
\[ \frac{\partial o_{t\text{-}1}}{\partial \text{net}_o} = o_{t\text{-}1}(1-o_{t\text{-}1}) = 0.5250 \times 0.4750 = \mathbf{0.2494} \]
Gradient at the weighted sum (multiply the trunk so far)
\[ \frac{\partial L}{\partial \text{net}_o} = (-1.3147)(0.2717)(0.2494) = \mathbf{-0.0891} \]

The last segment — three variants of one rule

\(\text{net}_o = w_{xo_{t\text{-}1}}\!\cdot x_{t\text{-}1} + w_{ho_{t\text{-}1}}\!\cdot h_{t\text{-}2} + b_{o_{t\text{-}1}}\). Each parameter’s derivative is simply the value it was multiplied by:

Step O3 — one line per parameter
\[ \frac{\partial L}{\partial w_{xo_{t\text{-}1}}} = -0.0891 \times x_{t\text{-}1} = -0.0891 \times 0.5 = \mathbf{-0.0445} \] \[ \frac{\partial L}{\partial w_{ho_{t\text{-}1}}} = -0.0891 \times h_{t\text{-}2} = -0.0891 \times 0 = \mathbf{0} \] \[ \frac{\partial L}{\partial b_{o_{t\text{-}1}}} = -0.0891 \times 1 = \mathbf{-0.0891} \]
Updates (\(w^{new} = w^{old} - 0.1\cdot\text{grad}\)): \(w_{xo}: 0.4 \to \mathbf{0.4045}\);   \(w_{ho}: 0.5 \to \mathbf{0.5}\) (unchanged — it multiplied \(h_{t\text{-}2}=0\), so it had no influence to correct);   \(b_o: -0.1 \to \mathbf{-0.0911}\)
The Cell-State Trunk — \(\partial L / \partial c_{t\text{-}1}\) (shared by the remaining six parameters)

Everything that is not in the output gate reached the loss by first building the cell state. So before touching those parameters, we extend the trunk from \(h\) down to \(c\) — two more segments, computed once, reused six times:

The trunk from the loss down to the cell state. \(h = o \times \tanh(c)\), so going backward we pick up a factor of \(o\) (Step C1), then the tanh derivative (Step C2).

Step C1 — through h = o × tanh(c), this time with respect to tanh(c)
\[ \frac{\partial h_{t\text{-}1}}{\partial \tanh(c_{t\text{-}1})} = o_{t\text{-}1} = \mathbf{0.5250} \]
Step C2 — through the tanh
\[ \frac{\partial \tanh(c_{t\text{-}1})}{\partial c_{t\text{-}1}} = 1 - \tanh^2(c_{t\text{-}1}) = 1 - (0.2717)^2 = \mathbf{0.9262} \]
Gradient at the cell state (multiply the trunk)
\[ \frac{\partial L}{\partial c_{t\text{-}1}} = (-1.3147)(0.5250)(0.9262) = \mathbf{-0.6393} \]
Every remaining parameter’s chain now starts from \(-0.6393\). Notice how little the tanh shrank the gradient (0.9262 ≈ 1): with \(c\) small, the cell state is a near-transparent gradient highway.

The three-way split at the cell state

The cell state was built as \(c_{t\text{-}1} = f\cdot c_{t\text{-}2} + i1 \cdot i2\). Three quantities went in, so the gradient splits three ways — and each factor is, as always, whatever the quantity was multiplied by:

One line per branch
\[ \frac{\partial c_{t\text{-}1}}{\partial f_{t\text{-}1}} = c_{t\text{-}2} = \mathbf{0} \qquad \frac{\partial c_{t\text{-}1}}{\partial i1_{t\text{-}1}} = i2_{t\text{-}1} = \mathbf{0.5717} \qquad \frac{\partial c_{t\text{-}1}}{\partial i2_{t\text{-}1}} = i1_{t\text{-}1} = \mathbf{0.4875} \]
Branch 2 — “% Potential Memory” (sigmoid block): \(w_{xi1}\), \(w_{hi1}\), \(b_{i1}\)

The i1 branch: from the cell state, back through the multiplication (× i2), through the sigmoid, to the three parameters.

Step I1-1 — into the branch (× the other factor, i2)
\[ \frac{\partial L}{\partial i1_{t\text{-}1}} = -0.6393 \times 0.5717 = \mathbf{-0.3655} \]
Step I1-2 — through the sigmoid
\[ \frac{\partial i1_{t\text{-}1}}{\partial \text{net}_{i1}} = i1(1-i1) = 0.4875 \times 0.5125 = \mathbf{0.2498} \qquad \frac{\partial L}{\partial \text{net}_{i1}} = -0.3655 \times 0.2498 = \mathbf{-0.0913} \]
Step I1-3 — last segment, one line per parameter
\[ \frac{\partial L}{\partial w_{xi1_{t\text{-}1}}} = -0.0913 \times 0.5 = \mathbf{-0.0457} \qquad \frac{\partial L}{\partial w_{hi1_{t\text{-}1}}} = -0.0913 \times 0 = \mathbf{0} \qquad \frac{\partial L}{\partial b_{i1_{t\text{-}1}}} = \mathbf{-0.0913} \]
Updates: \(w_{xi1}: 0.3 \to \mathbf{0.3046}\);   \(w_{hi1}: 0.6 \to \mathbf{0.6}\) (unchanged);   \(b_{i1}: -0.2 \to \mathbf{-0.1909}\)
Branch 3 — “Potential Long Memory” (tanh block): \(w_{xi2}\), \(w_{hi2}\), \(b_{i2}\)

The i2 branch: same shape as i1, but the activation is tanh — so Step I2-2 uses the tanh derivative instead of the sigmoid’s.

Step I2-1 — into the branch (× the other factor, i1)
\[ \frac{\partial L}{\partial i2_{t\text{-}1}} = -0.6393 \times 0.4875 = \mathbf{-0.3117} \]
Step I2-2 — through the tanh
\[ \frac{\partial i2_{t\text{-}1}}{\partial \text{net}_{i2}} = 1 - i2^2 = 1-(0.5717)^2 = \mathbf{0.6732} \qquad \frac{\partial L}{\partial \text{net}_{i2}} = -0.3117 \times 0.6732 = \mathbf{-0.2098} \]
Step I2-3 — last segment, one line per parameter
\[ \frac{\partial L}{\partial w_{xi2_{t\text{-}1}}} = -0.2098 \times 0.5 = \mathbf{-0.1049} \qquad \frac{\partial L}{\partial w_{hi2_{t\text{-}1}}} = -0.2098 \times 0 = \mathbf{0} \qquad \frac{\partial L}{\partial b_{i2_{t\text{-}1}}} = \mathbf{-0.2098} \]
Updates: \(w_{xi2}: 0.7 \to \mathbf{0.7105}\);   \(w_{hi2}: 0.2 \to \mathbf{0.2}\) (unchanged);   \(b_{i2}: 0.3 \to \mathbf{0.3210}\)
Compare I1-2 and I2-2: the tanh derivative (0.6732) is 2.7× the sigmoid derivative (0.2498) at these values. The gradient flows into the value-proposing block far more easily than into the gating block — the network is being corrected most strongly on what it proposed to remember, and more gently on how much of it to let in.
Branch 4 — The Forget Gate: \(w_{xf}\), \(w_{hf}\), \(b_f\) (all zero this step)

The forget branch begins with \(\partial c_{t\text{-}1} / \partial f_{t\text{-}1} = c_{t\text{-}2}\) — and \(c_{t\text{-}2} = 0\). That single zero, right at the branch point, multiplies through everything downstream:

The whole branch in three lines
\[ \frac{\partial L}{\partial f_{t\text{-}1}} = -0.6393 \times c_{t\text{-}2} = -0.6393 \times 0 = \mathbf{0} \] \[ \frac{\partial L}{\partial \text{net}_f} = 0 \times f(1-f) = 0 \times 0.2425 = \mathbf{0} \] \[ \frac{\partial L}{\partial w_{xf}} = \frac{\partial L}{\partial w_{hf}} = \frac{\partial L}{\partial b_f} = \mathbf{0} \]
This is not a bug — it is the math being honest. The forget gate’s only job is deciding what fraction of the old memory to keep. At \(t\text{-}1\) the old memory was empty (\(c_{t\text{-}2}=0\)), so the gate’s decision had no effect on anything — and a parameter that had no effect earns no correction. At time step \(t\), where \(c_{t\text{-}1}=0.2787 \neq 0\), this branch comes alive.

The chain column IS the map. Read any row and you can trace its factors on the master diagram: the first number is the trunk (\(-1.3147\) if the path goes through \(o\); \(-0.6393\) if it goes through \(c\)), the middle numbers are the branch segments, and the last number is what the parameter was multiplied by in the forward pass (\(x=0.5\), \(h_{t\text{-}2}=0\), or \(1\) for a bias).
Two patterns worth noticing in the final table. (1) Every hidden weight (\(w_{ho}, w_{hi1}, w_{hi2}, w_{hf}\)) got gradient 0 — all for the same reason: they multiplied \(h_{t\text{-}2}=0\) in the forward pass. A weight that touched nothing learns nothing. (2) Every non-zero gradient is negative, so every updated weight moved up — consistent with one story: the output (0.1426) was below the target (0.8), and every live parameter is being nudged in the direction that raises it. At time step \(t\), with \(h_{t\text{-}1}\) and \(c_{t\text{-}1}\) both non-zero, all twelve parameters participate — and the gradient additionally flows backward through time into this step’s computation. That is Backpropagation Through Time, and it is the natural next document.
