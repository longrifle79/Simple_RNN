Understanding Recurrent Neural Networks (RNNs)

A clear explanation using the "How To Make" example from the video

What is an RNN? A Recurrent Neural Network is a type of neural network designed to work with sequences of data (like words in a sentence, time series, or music notes). Unlike regular neural networks, RNNs have "memory" — they can remember information from previous steps in the sequence.

The Diagram Explained

The Unfolded RNN for the sequence "How → To → Make"

(This is the standard way to draw an RNN when we "unroll" it across time steps)

What each element represents:

Element What it is In this example
x₁, x₂, x₃
(inputs)		 The input at each time step. Usually a vector (e.g. word embedding or one-hot encoding of the word). x₁ = "How"
x₂ = "To"
x₃ = "Make"
h₁, h₂, h₃
(hidden states)		 The "memory" or "context" of the network at each time step. hₜ contains information about all previous inputs (x₁ to xₜ). h₁ processes "How"
h₂ processes "To" + memory from h₁
h₃ processes "Make" + memory from h₂
y₁, y₂, y₃
(outputs)		 The output at each time step. In language modeling, this is often the predicted next word (as a probability distribution). y₁ might predict "To"
y₂ might predict "Make"
y₃ might predict what comes after "Make" (e.g. "a cake")
U (input weights) The weight matrix that transforms the input xₜ into the hidden state. Same U is used at every time step (shared weights)
V (recurrent weights) The weight matrix that transforms the previous hidden state h_{t-1} into the current hidden state. This is what gives the RNN its "memory" — it carries information forward in time.
W (output weights) The weight matrix that transforms the hidden state hₜ into the output yₜ. Same W is used at every time step.

The Math Behind the RNN

At each time step t, the RNN does two main things:

1. Update the hidden state (memory):
\[ h_t = \tanh(U \cdot x_t + V \cdot h_{t-1}) \]
2. Produce an output:
\[ y_t = \text{softmax}(W \cdot h_t) \]

Where:

  • tanh is the activation function (keeps values between -1 and 1)
  • softmax turns the output into probabilities (useful for predicting the next word)
  • h₀ is usually initialized to zeros (or a learned vector)
Key Idea: The same weights U, V, and W are used at every time step. This is what allows the RNN to handle sequences of any length.

A Short Numerical Example: Processing "How → To → Make"

Let's walk through a very simplified numerical example. We'll use small vectors (size 2) to keep the math manageable.

Assumptions for this toy example:

  • Hidden size = 2
  • We use random small weight matrices (in reality these are learned)
  • We show the calculations for the first two time steps in detail

Time Step 1: Input = "How" (x₁)

1 Input vector x₁ (simplified embedding for "How")
\[ x_1 = \begin{bmatrix} 1.0 \\ 0.0 \end{bmatrix} \]
2 Initialize h₀ = [0, 0] (no previous memory)
3 Compute hidden state h₁
\[ h_1 = \tanh(U \cdot x_1 + V \cdot h_0) \]

(In practice U and V are matrices. Here we show the idea.)

4 Compute output y₁ (prediction of the next word after "How")
\[ y_1 = \text{softmax}(W \cdot h_1) \]

y₁ might give high probability to the word "To".

Time Step 2: Input = "To" (x₂)

1 Input vector x₂
\[ x_2 = \begin{bmatrix} 0.0 \\ 1.0 \end{bmatrix} \] (embedding for "To")
2 Update hidden state h₂ using h₁ (the memory from previous step)
\[ h_2 = \tanh(U \cdot x_2 + V \cdot h_1) \]

h₂ now contains information about both "How" and "To". This is the power of recurrence!

3 Compute output y₂
\[ y_2 = \text{softmax}(W \cdot h_2) \]

y₂ might now predict "Make" with high probability.

Time Step 3: Input = "Make" (x₃)

Same process repeats:

\[ h_3 = \tanh(U \cdot x_3 + V \cdot h_2) \]
\[ y_3 = \text{softmax}(W \cdot h_3) \]
After processing "How To Make", the final hidden state h₃ contains a rich summary of the entire sequence.
This h₃ can be used for many tasks: predicting the next word, classifying the sentence, generating more text, etc.

Key Takeaways

  • hₜ (hidden state) = the memory of the network. It gets updated at every time step and carries information forward.
  • yₜ (output) = what the network predicts or produces at step t.
  • The same weights (U, V, W) are reused at every time step → this allows the network to handle variable-length sequences.
  • Backpropagation Through Time (BPTT) is used to train RNNs — gradients flow backward through the entire sequence.
  • This architecture is the foundation for more advanced models like LSTMs and GRUs (which solve the "vanishing gradient" problem of basic RNNs).

Why this diagram is so powerful

The simple structure shown in the video (h₁ → h₂ → h₃ with shared weights) allows neural networks to process sequences like sentences, music, video frames, or time series data while maintaining context across time.
