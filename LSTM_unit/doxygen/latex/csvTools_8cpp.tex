\doxysubsection{Detailed Description}
Implementation of CSV parsing and printing utilities for the Simple\+NN project. 

This file contains the definitions for functions declared in \doxylink{csvTools_8h}{csv\+Tools.\+h}. It provides:\+
\begin{DoxyItemize}
\item Low-\/level char-\/by-\/char CSV parsing into nested std::\+list structures.
\item Header skipping and basic error handling.
\item Directory scanning for multiple CSV files.
\item Structured printing for verification and debugging.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The parser is designed for simple numeric CSVs (no quoted fields, no escaped commas). It uses fixed-\/size buffering (100 chars per field) for simplicity—suitable for small datasets. For production use, consider libraries like rapidcsv for robustness.
\end{DoxyNote}
