LSTM Backpropagation — Updating a Single Weight \(w_{xo_{t\text{-}1}}\)

Same example as the forward pass. One weight, one path, one derivative per segment — with the path drawn at every step.

About this document. Backpropagation updates every weight in the LSTM, but doing all twelve at once hides the core idea behind a wall of arithmetic. So here we follow one weight from start to finish: \(w_{xo_{t\text{-}1}}\), the input weight inside the output gate. Once this single path is clear, every other weight follows the exact same pattern.

The one idea to hold onto: during the forward pass, the weight’s influence travelled along a specific path to reach the loss. Backpropagation walks that same path in reverse, and every segment of the path contributes exactly one derivative to the chain rule. The diagram below is the whole document in one picture — each step after it just zooms in on one red arrow.

Values carried over from the forward pass (t−1)

  • \(x_{t\text{-}1} = 0.5\) — the input
  • \(\text{net}_{o} = 0.1\) — the output gate’s weighted sum
  • \(o_{t\text{-}1} = \sigma(\text{net}_o) = 0.5250\) — the output gate value
  • \(\tanh(c_{t\text{-}1}) = 0.2717\) — tanh of the new cell state
  • \(h_{t\text{-}1} = o_{t\text{-}1}\cdot\tanh(c_{t\text{-}1}) = 0.1426\) — the network’s output
  • \(w_{xo_{t\text{-}1}} = 0.4\) — the weight we will update; learning rate \(\alpha = 0.1\)
  • \(\text{target} = 0.8\),   loss \(L = (\text{target} - h_{t\text{-}1})^2 = (0.8-0.1426)^2 = 0.4321\)

The Whole Journey in One Picture

Read the purple row left to right — that is the forward pass: the weight is multiplied by the input to help form \(\text{net}_o\), the sigmoid turns \(\text{net}_o\) into the gate value \(o\), multiplying by \(\tanh(c)\) gives the output \(h\), and comparing \(h\) to the target gives the loss. The dashed boxes above are the other quantities that join the path along the way — each one will reappear as a number inside one of the derivatives.

The full gradient path. Each red arrow below the pipeline is one factor of the chain rule — the local derivative of the forward operation directly above it. Multiply the four red arrows together and you have \(\partial L / \partial w_{xo}\).

Where does each part of the equation come from? Look at the pairing: every red arrow sits directly under one purple arrow. The purple arrow says what the forward pass did on that segment; the red arrow is that operation’s derivative. “Multiply by \(x\)” differentiates to \(x\). “Apply sigmoid” differentiates to \(o(1-o)\). “Multiply by \(\tanh(c)\)” differentiates to \(\tanh(c)\). “Square the difference from target” differentiates to \(-2(\text{target}-h)\). Nothing in the chain rule is invented — every factor is the shadow of a forward operation.
\[ \frac{\partial L}{\partial w_{xo_{t\text{-}1}}} = \underbrace{\frac{\partial L}{\partial h_{t\text{-}1}}}_{\text{Step 1}} \cdot \underbrace{\frac{\partial h_{t\text{-}1}}{\partial o_{t\text{-}1}}}_{\text{Step 2}} \cdot \underbrace{\frac{\partial o_{t\text{-}1}}{\partial \text{net}_o}}_{\text{Step 3}} \cdot \underbrace{\frac{\partial \text{net}_o}{\partial w_{xo_{t\text{-}1}}}}_{\text{Step 4}} \]
Why no cell-state branch? Some weights (the forget and input-gate weights) reach the loss through two routes, because they change the cell state \(c_{t\text{-}1}\), which feeds both the output and the next time step. But \(w_{xo_{t\text{-}1}}\) lives in the output gate, which reads the cell state without ever changing it. Notice in the diagram that \(\tanh(c)\) enters the path from a dashed box outside it — the path never loops through the cell state. One clean route; that is exactly why we start here.

We number the steps starting from the loss, because that is the direction backpropagation actually works: it begins with the error and walks toward the weight.

Step 1 — The rightmost segment: \(\partial L / \partial h_{t\text{-}1}\)

Step 1 crosses the last segment of the path: from the loss back to the output \(h\). The forward operation on this segment was “compare to target and square.”

The forward pass ended by computing \(L = (\text{target} - h_{t\text{-}1})^2\). This segment’s derivative asks: if \(h\) rose slightly, how would \(L\) change? Differentiating (the inner term carries a \(-1\), which flips the sign):

Symbolic
\[ \frac{\partial L}{\partial h_{t\text{-}1}} = -2\,(\text{target} - h_{t\text{-}1}) \]
With numbers — the target (0.8) is the dashed box that joined the path here
\[ \frac{\partial L}{\partial h_{t\text{-}1}} = -2\,(0.8 - 0.1426) = -2\,(0.6574) = \mathbf{-1.3147} \]
The gradient is negative: increasing \(h_{t\text{-}1}\) would decrease the loss. That makes sense — our output was too low, so we want it higher.
Step 2 — Through the multiplication: \(\partial h_{t\text{-}1} / \partial o_{t\text{-}1}\)

Step 2 crosses the segment where the gate value \(o\) was multiplied by \(\tanh(c)\) to form \(h\). The derivative of “multiply by \(\tanh(c)\)” is simply \(\tanh(c)\) itself.

On this segment the forward pass computed \(h_{t\text{-}1} = o_{t\text{-}1}\cdot\tanh(c_{t\text{-}1})\). Since \(\tanh(c_{t\text{-}1})\) does not depend on \(o_{t\text{-}1}\) (it came in from the cell state — the dashed box), it acts as a constant multiplier, and the derivative of “multiply by a constant” is that constant:

Symbolic
\[ \frac{\partial h_{t\text{-}1}}{\partial o_{t\text{-}1}} = \tanh(c_{t\text{-}1}) \]
With numbers — reusing the forward-pass value
\[ \frac{\partial h_{t\text{-}1}}{\partial o_{t\text{-}1}} = \mathbf{0.2717} \]
Step 3 — Through the sigmoid: \(\partial o_{t\text{-}1} / \partial \text{net}_o\)

Step 3 crosses the sigmoid segment: from the gate value \(o\) back to the weighted sum \(\text{net}_o\).

The gate value came from a sigmoid: \(o_{t\text{-}1} = \sigma(\text{net}_o)\). The sigmoid’s derivative has the famously tidy form \(\sigma(1-\sigma)\), and we already know \(\sigma = o_{t\text{-}1} = 0.5250\) from the forward pass — no recomputation needed:

Symbolic
\[ \frac{\partial o_{t\text{-}1}}{\partial \text{net}_o} = o_{t\text{-}1}\,(1 - o_{t\text{-}1}) \]
With numbers
\[ \frac{\partial o_{t\text{-}1}}{\partial \text{net}_o} = 0.5250\,(1 - 0.5250) = 0.5250 \times 0.4750 = \mathbf{0.2494} \]
Step 4 — The leftmost segment: \(\partial \text{net}_o / \partial w_{xo_{t\text{-}1}}\)

Step 4 crosses the first segment: from the weighted sum back to the weight itself. The forward operation was “multiply the weight by \(x\)” — so the derivative is \(x\).

The output gate’s weighted sum was \(\text{net}_o = w_{xo_{t\text{-}1}}\cdot x_{t\text{-}1} + w_{ho_{t\text{-}1}}\cdot h_{t\text{-}2} + b_{o_{t\text{-}1}}\). Only the first term contains our weight — the other two terms (grayed out beneath the diagram’s sum box) contribute nothing to this derivative:

Symbolic
\[ \frac{\partial \text{net}_o}{\partial w_{xo_{t\text{-}1}}} = x_{t\text{-}1} \]
With numbers — the input (0.5) is the dashed box that joined the path here
\[ \frac{\partial \text{net}_o}{\partial w_{xo_{t\text{-}1}}} = \mathbf{0.5} \]
A nice pattern: the gradient of any weighted sum with respect to one of its weights is just the value that weight was multiplied by in the forward pass. The input weight’s partial is the input \(x\); the hidden weight’s partial would be \(h\); the bias’s partial is \(1\).

Assemble the Full Gradient

Now read the master diagram one more time: four red arrows, four numbers. Multiply them along the path:

Symbolic
\[ \frac{\partial L}{\partial w_{xo_{t\text{-}1}}} = \frac{\partial L}{\partial h_{t\text{-}1}} \cdot \frac{\partial h_{t\text{-}1}}{\partial o_{t\text{-}1}} \cdot \frac{\partial o_{t\text{-}1}}{\partial \text{net}_o} \cdot \frac{\partial \text{net}_o}{\partial w_{xo_{t\text{-}1}}} \]
Substitute the four numbers (Step 1 × Step 2 × Step 3 × Step 4)
\[ \frac{\partial L}{\partial w_{xo_{t\text{-}1}}} = (-1.3147)\,(0.2717)\,(0.2494)\,(0.5) \] \[ = \mathbf{-0.0445} \]
The gradient of the loss with respect to \(w_{xo_{t\text{-}1}}\) is \(-0.0445\). Negative means: increasing this weight reduces the loss, so the update will push the weight up.
Final Step — Update the Weight

Gradient descent moves the weight a small step in the direction that lowers the loss, scaled by the learning rate \(\alpha = 0.1\):

Symbolic
\[ w_{xo_{t\text{-}1}}^{\text{new}} = w_{xo_{t\text{-}1}}^{\text{old}} - \alpha\,\frac{\partial L}{\partial w_{xo_{t\text{-}1}}} \]
With numbers
\[ w_{xo_{t\text{-}1}}^{\text{new}} = 0.4 - (0.1)(-0.0445) = 0.4 + 0.00445 = \mathbf{0.4045} \]
The weight moved from \(0.4000\) to \(0.4045\) — a small step upward, exactly as the negative gradient predicted. Subtracting a negative number adds to the weight.

What changes for other weights? Only the leftmost segments of the path. Steps 1 and 2 are shared by everything on the output side. To update the output gate’s hidden weight \(w_{ho_{t\text{-}1}}\), you would keep Steps 1–3 identical and only swap Step 4 to use \(h_{t\text{-}2}\) instead of \(x_{t\text{-}1}\). Weights in the forget and input gates need a longer path because they reach the loss through the cell state — their diagram would show the path looping through \(c_{t\text{-}1}\), and the chain rule would pick up one extra factor per extra segment.
