\doxysubsection{Detailed Description}
Program entry point for the Simple\+NN linear regression CSV data loader. 

This file contains the {\ttfamily \doxylink{main_8cpp_ae66f6b31b5ad750f1fe042a706a4e3d4}{main()}} function, which serves as the executable\textquotesingle{}s starting point. It demonstrates the usage of the CSV utilities from \doxylink{csvTools_8h}{csv\+Tools.\+h}/\+cpp:\+
\begin{DoxyItemize}
\item Specifies a hard-\/coded directory containing CSV datasets.
\item Loads all CSV files into a 3D nested list structure (files → rows → float values).
\item Prints the total number of files loaded.
\item Outputs the full contents of all tables for verification.
\end{DoxyItemize}

The program is designed as a simple command-\/line tool for quick data inspection and validation during development of regression models in the Simple\+NN project.

\begin{DoxyNote}{Note}

\begin{DoxyItemize}
\item The CSV directory path is currently hard-\/coded for convenience. In a production or reusable tool, this should be passed as a command-\/line argument (e.\+g., via argc/\+argv) or configured via a file/\+environment variable.
\item No error handling beyond what csv\+Tools provides—assumes valid numeric CSVs.
\item Output is to stdout; suitable for piping or redirection (e.\+g., {\ttfamily ./\+main \texorpdfstring{$>$}{>} output.\+txt}).
\end{DoxyItemize}
\end{DoxyNote}
\begin{DoxyWarning}{Warning}

\begin{DoxyItemize}
\item Relies on csv\+Tools for parsing—see its documentation for limitations (e.\+g., no support for quoted fields, fixed buffer size).
\item Hard-\/coded path ties the executable to a specific filesystem location.
\end{DoxyItemize}
\end{DoxyWarning}
